1Sign in with Google

Emails are sent from your own Gmail account through the Gmail API. This page only asks for permission to send mail. It can't read your inbox. Nothing goes through any other server.

First time? How to get your own Client ID (about 5 minutes, free)
  1. Go to console.cloud.google.com and create a project, e.g. “My Mail Merge”.
  2. APIs & Services → Library → enable Gmail API.
  3. APIs & Services → OAuth consent screen → External → fill in an app name and your email → add your own Gmail address under Test users.
  4. Credentials → Create credentials → OAuth client ID → Application type: Web application.
  5. Authorized JavaScript origins → add → Create → paste the Client ID above.
  6. When you sign in, Google shows “Google hasn't verified this app”. That's expected, because it's your own app: Continue.

2Import CSV & match fields

One row per recipient. The file stays in this browser tab. It's never uploaded or saved, and it's gone when you close the tab. If your links log people in, treat the CSV like a password file.

3Draft the email

Click a field to insert it. Any CSV column can be used, e.g. {{Company}}. {{Button}} on its own line becomes a button that opens that person's own link.

Best way to copy it: open an email you sent in Gmail (or Gmail → Settings → Signature), select the whole signature, copy, and paste here. It's added at the end of every email, or wherever you put {{Signature}}.

Always send yourself a test first. Each person gets their own email with their own link, never a group email or BCC. Gmail limits: about 500 emails a day for personal accounts, about 2,000 for Google Workspace.
